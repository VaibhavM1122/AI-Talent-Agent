# 🤖 AI Talent Scouting & Engagement Agent

##  Features
- Job Description Parsing
- Candidate Matching (TF-IDF)
- Interest Simulation
- Ranked Shortlist

##  Tech Stack
- Python
- Streamlit
- Pandas
- Scikit-learn

##  Run Locally
pip install -r requirements.txt  
streamlit run app.py

##  Sample Input
"Looking for Data Analyst with Python, SQL"

##  Output
Ranked candidates with scores
